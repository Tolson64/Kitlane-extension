你一定有过这种时刻：明明存过一个能把图片压小的网站，到用的时候怎么也想不起叫什么，翻了半天收藏夹，最后又重新搜了一遍，找到另一个。

Kitlane 想解决的就是这一刻。它读取你浏览器里已有的收藏夹，按用途给每条收藏打上标签，你只要输入「把图片弄小的网站」，就能把对应的收藏找出来。

## 效果示例

在搜索框里直接描述要做的事：

| 你输入 | 排在最前面的收藏 |
|---|---|
| 公众号排版 | 秀米、135 编辑器、mdnice |
| 背单词 | 扇贝、多邻国 |
| 做 PPT 的 AI 工具 | AiPPT、iSlide、Gamma |
| 海外收款 | PingPong、连连国际、Payoneer、Wise |
| 亚马逊选品工具 | 卖家精灵、Jungle Scout、Helium 10 |
| 把图片弄小一点的网站 | Squoosh、TinyPNG（同时带出抠图、修图类工具） |

以上是在作者自建的 474 条样本收藏上、不填任何模型 Key、纯本地搜索得到的结果。需要时可以再点「智能搜索」，让你自己配置的大模型对结果重新排序。

## 它能做什么

- **不填 Key 也能自动分类。** 导入收藏夹后立刻按网站知识库（约 920 个常见网站）、网址特征（GitHub 仓库、论文页、视频页、文档、博客）、你自己的文件夹名和网页公开简介分类，不调用任何模型。
- **按任务找，不靠记名字。** 本地搜索把口语说法对应到标签（「抠图」→ 图片处理，「财报」→ 财报公告）；可选的智能搜索先在本地筛出前 30 条，再交给大模型重排。
- **收藏集跟着标签走。** 收藏集按标签自动收录，标签越准，收藏集越准；新建时会按名称推荐标签。
- **自带大模型，可选。** 支持任何 OpenAI 兼容接口（云端或 Ollama、LM Studio 等本机模型），也支持 Jev 决策模型。大模型可以写摘要、从你的标签库里选标签、判断收藏集规则。
- **私密内容只在本机。** 内部系统、在线文档、账号后台、网盘分享、带凭证的链接、成人内容，以及读取时发现需要登录的页面，都不会发给任何模型，也不会被抓取。

## 实测效果

用同一套规则，对比「不配任何模型」时没能分到类的收藏占比（越低越好）：

| 收藏来源 | 旧规则 | 现在 |
|---|---|---|
| 作者本人的真实收藏（57 条） | 78% | **32%** |
| Hacker News 与 Lobsters 高赞链接（405 条，不是挑选的） | 75% | **45%**，读取网页简介后 **29%** |

搜索方面，用 60 个中文口语查询、474 条样本收藏测试：正确结果出现在本地排序前 30 条的比例 **97%**，前 5 条的比例 **92%**。

> 这些数字有局限：作者本人的收藏只有 57 条；后一项测试的样本和查询都由作者编写，结果偏乐观，只适合用来比较改动前后。真实用户的数据还很缺。如果你愿意提供匿名的汇总统计，欢迎提 Issue。

## 和同类插件的区别

Chrome 商店里的「AI 书签」类插件已经有二十多个，大多数主打「一键把书签整理成文件夹」，并且需要先填 API Key 才能用。Kitlane 的取舍不同：

| | 多数 AI 书签插件 | Kitlane |
|---|---|---|
| 核心功能 | 把书签整理成文件夹 | 按任务找回，不改你的文件夹 |
| 不填 Key 能用吗 | 通常不能 | 能，自动分类与搜索都在本地完成 |
| 私密内容 | 多数只能手动排除 | 内部系统、在线文档、账号后台等自动识别，只在本机处理 |
| 数据去向 | 视产品而定 | 收藏库只存在你的浏览器里；只有你开启模型时，才把规定的内容发给你配置的服务商 |

## 安装

目前还没有上架浏览器商店，需要自己构建（需要 Node.js 20 以上）：

```bash
git clone https://github.com/Tolson64/Kitlane-extension.git
cd Kitlane-extension
npm ci
npm run build          # Chrome：输出到 .output/chrome-mv3
npm run build:edge     # Edge：输出到 .output/edge-mv3
```

然后打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开「开发者模式」，点「加载已解压的扩展程序」，选择输出文件夹。

## 开始使用

1. 点浏览器工具栏上的 Kitlane 图标，打开侧边栏。
2. 点右上角的刷新图标，导入你的收藏夹。
3. 在搜索框里描述要做的事，直接看结果。
4. （可选）点右上角齿轮，选择模型来源、填好接口地址和 Key，勾选「允许模型分析公开收藏」，之后可以用「智能搜索」。界面语言也在这里切换。

## 隐私

- 收藏库、标签、备忘、搜索索引都保存在你浏览器本地的数据库里；导出的 JSON 不含 API Key。
- 不开启模型时，不会向任何第三方发送你的收藏内容。
- 开启后，发送的是搜索描述，以及公开收藏的标题、去掉参数的网址路径、原收藏夹名和网页简介。个人备忘、自定义标题、私密收藏从不发送。
- 读取网页简介需要你授权具体的网站，不会一次申请所有网站的权限，也不携带登录信息。

完整的私密识别规则和数据流向见[技术说明](docs/technical-notes.zh.md)。

## 已知不足

- 还没有云同步，也没有「导入 JSON」，换电脑需要重新导入收藏夹，手动调整过的标签不会跟着走。
- 目前只支持 Chrome 与 Edge，Safari 暂不支持。
- API Key 以明文保存在浏览器本地数据库里（这是浏览器扩展的常见做法，但你需要知道）。
- 英文界面和英文标签是新加的，可能还有不通顺的地方，欢迎提 Issue。
- 智能搜索对中文口语、俗语的理解取决于你选的模型，我们还没有系统比较过不同模型。
- 没有网页简介的个人博客和小众网站，不配模型时仍可能分不了类。
