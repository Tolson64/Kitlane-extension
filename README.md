# 🔖 Kitlane

> **记不住名字，也能找到你收藏过的工具。**

[English](README.en.md) · [MIT](LICENSE) · Chrome / Edge 侧边栏扩展 · 中英双语 🌏

明明存过一个能把图片压小的网站，要用的时候，死活想不起来叫什么。

翻十分钟收藏夹，放弃，重新搜一遍，找到的还是另一个。

Kitlane 就管这一件事 🎯 它读你浏览器里已有的收藏，按用途打好标签。你说一句「把图片弄小的网站」，它把那一个翻出来。

## 🔍 先试试

直接说你要做什么。下面是纯本地搜索的结果，不用模型，也不用填 Key 👇

| 你说 | 它翻出来的 |
|---|---|
| 公众号排版 | 秀米、135 编辑器、mdnice ✍️ |
| 背单词 | 扇贝、多邻国 📖 |
| 做 PPT 的 AI 工具 | AiPPT、iSlide、Gamma 📊 |
| 海外收款 | PingPong、连连国际、Payoneer、Wise 💸 |
| 亚马逊选品工具 | 卖家精灵、Jungle Scout、Helium 10 📦 |
| 把图片弄小一点的网站 | Squoosh、TinyPNG 🖼️ |

（作者自建的 474 条样本收藏上跑出来的）想再准一点，点「智能搜索」，让你自己配的大模型帮着重新排个序。

## 🧰 它能干嘛

- 🆓 **不填 Key 也能分类**　导入就分好，靠的是 920 个常见网站、网址特征、你的文件夹名和网页简介，不调用任何模型
- 🗣️ **按任务找**　口语直接搜，「抠图」能找到图片处理，「财报」能找到财报公告
- 🏷️ **收藏集跟着标签走**　标签越准，收藏集越准，新建时还会按名字推荐标签
- 🤖 **模型自带，可选**　任何兼容 OpenAI 的接口都行，云端、Ollama、LM Studio 都支持，也支持 Jev
- 🔒 **私密的只在本机**　内部系统、在线文档、账号后台、网盘分享、带凭证的链接、成人内容，不发给模型，也不去抓

## 📊 实测

不配任何模型时，没能分到类的收藏占多少，越低越好。

| 收藏来源 | 以前 | 现在 |
|---|---|---|
| 作者自己的收藏（57 条） | 78% | **32%** |
| Hacker News 与 Lobsters 高赞链接（405 条，没有挑过） | 75% | **45%**，读完网页简介后 **29%** |

搜索这边，60 个中文口语问法、474 条样本收藏，正确结果落在本地前 30 条的有 **97%**，落在前 5 条的有 **92%** 🎉

> ⚠️ 说句实话。作者自己的收藏只有 57 条，搜索测试的样本和问法也是作者写的，数字偏乐观，只适合拿来比改动前后。真实用户的数据还很缺，如果你愿意给一份匿名的汇总统计，欢迎提 Issue 🙏

## 🆚 哪里不一样

Chrome 商店里的 AI 书签插件已经二十多个了。大多数主打「一键整理成文件夹」，而且得先填 API Key 才能用。

| | 多数 AI 书签插件 | Kitlane |
|---|---|---|
| 干什么 | 把书签整理成文件夹 | 按任务找回，你的文件夹不动 |
| 没 Key 能用吗 | 通常不能 | 能，分类和搜索都在本地 |
| 私密内容 | 多半要手动排除 | 自动识别，只在本机处理 |

## 📦 安装

还没上架商店，先自己构建（要 Node.js 20 以上）。

```bash
git clone https://github.com/Tolson64/Kitlane-extension.git
cd Kitlane-extension
npm ci
npm run build          # Chrome 输出到 .output/chrome-mv3
npm run build:edge     # Edge 输出到 .output/edge-mv3
```

打开 `chrome://extensions`（Edge 是 `edge://extensions`），开「开发者模式」，点「加载已解压的扩展程序」，选刚才的输出文件夹。

## 🚀 用起来

1. 点工具栏上的 Kitlane 图标，打开侧边栏
2. 点右上角的刷新图标，导入收藏夹
3. 在搜索框里说你要做什么
4. 想用智能搜索，点齿轮，选模型、填地址和 Key，勾上「允许模型分析公开收藏」。界面语言也在这里换 ⚙️

## 🔒 隐私

- 收藏库、标签、备忘都存在你浏览器本地。导出的 JSON 不带 API Key
- 不开模型，就不会有任何东西发给第三方
- 开了模型，发的是你的搜索描述，加上公开收藏的标题、去掉参数的网址路径、收藏夹名和网页简介。备忘、自定义标题、私密收藏，一律不发
- 读网页简介要你逐个网站授权，不会一次要所有网站的权限，也不带登录信息

哪些算私密、数据怎么走，详见[技术说明](docs/technical-notes.zh.md) 📖

## 🚧 还没做好的

- ☁️ 没有云同步，也没有导入 JSON，换电脑要重新导入，手动改过的标签带不走
- 🌐 只支持 Chrome 和 Edge，Safari 暂时不行
- 🔑 API Key 明文存在浏览器本地数据库里，扩展里很常见，但你得知道
- 🔤 英文界面是新加的，可能有不通顺的地方，欢迎提 Issue
- 🧠 智能搜索懂不懂中文俗语，看你选的模型，我们还没系统比较过
- ✍️ 没有网页简介的个人博客，不配模型时可能还是分不出来
