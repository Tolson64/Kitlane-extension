# Kitlane 技术说明

> 这是详细的功能与隐私规则说明（给开发者和想了解细节的用户）。快速了解请看 [首页 README](../README.md)。


以本地 Chrome / Edge 收藏夹为基础的侧栏助手。按任务、科研、学习、工作和生活场景找回保存过的资源。

## 使用方式

「智能搜索」按钮位于搜索框右侧，运行时变成「停止」。设置页详细内容收进「连接与隐私说明」。

1. 重新加载原来安装的扩展目录，点击扩展图标打开侧栏；现有数据会原地升级，数据库名称保持不变。
2. 分类栏右侧的管理按钮打开「收藏集与标签包」。收藏集可新增、改名、删除、排序；删除收藏集保留链接。
3. 收藏集按标签收录：带所选标签的收藏自动进入收藏集，标签分类变准，收藏集随之变准。新建时输入名称会自动推荐并勾选相关标签（如「出海」推荐出海跨境的 6 个标签），可增删；也可选科研、出海等模板，模板带上该包全部标签并同时启用它。本地关键词和供模型判断的收录规则为可选补充。旧版从模板建的收藏集升级时自动补上对应标签。
4. 「场景标签包」提供通用资源、AI 工具、投资研究及其他场景包，默认启用除生活类（购物消费、旅行出行、健康家庭、兴趣娱乐、个人理财）以外的全部包；可以启停、修改、新增标签与标签包。未编辑过的内置包随插件更新自动获得新标签与词表；编辑过的包以用户保存的内容为准。
5. 卡片上的「整理」可以把同一链接加入多个收藏集，选择预设标签或添加自定义标签。标签正文最多 8 个字符（# 不计入），默认显示 4 个，可展开全部。处理状态可手动设为待读、待试、在用或已完成，并可筛选。

## 不需要模型 Key 的功能

- 导入浏览器收藏夹后立即分类，按以下顺序判断资源类型与标签：
  1. 常见网站知识库（`src/data/siteKnowledge.ts`，按网站给出类型和标签）与平台路径规则（区分 GitHub 仓库页与话题页、B 站视频页、arXiv 论文页、公众号文章等）。
  2. 通用网址惯例：`docs.` 子域名或 `/docs` 路径为文档，`/blog` 为文章，`/learn`、`/tutorial` 为教程。
  3. 标签词表匹配：标题、网址路径、原收藏夹名命中一个关键词即可；抓取的网页简介等原始资料需命中两个关键词或一个具体关键词（四字以上中文或英文词组），减少泛词误标。
  4. 同文件夹推断：自建文件夹里至少 3 条收藏、过半带同一场景标签时，补给同文件夹中还没有场景标签的收藏；资源类型同理，但不覆盖知识库已明确判断的网站。
- 网址规则更新后，旧收藏的类型也会按新规则实时判断；用户改过或模型判断过的类型不变。
- 不把生成摘要或个人备忘当作自动分类证据。
- 手动标签和收藏集选择优先，手动移出后不会被自动加回；处理不了的资源保留未分类。
- 本地搜索标题、自定义标题、网址、有效标签、摘要、功能、原始摘录、原收藏夹名和个人备忘，支持关键词、中文子串和文字模糊匹配。
- 网站图标由浏览器自动提供，与模型无关；无法取得时显示默认标识。
- 导出 JSON 包括原资产、收藏集、词表、有效标签、归属和模型判断，不包含模型设置或 API Key。

## 可选的模型分类

- 在模型设置中选择 Jev，填写 TypeSafe Key，并允许分析公开收藏。Jev 不需要先调用其他生成模型，使用官方 `/v1/systemone` 接口。
- Jev 根据每个收藏集的收录规则、启用标签包中每个标签的定义独立判断「适合／不适合／信息不足」，同一条收藏可匹配多个标签和收藏集。英文网页本身不表示适合出海。
- 收藏集管理中可归类已有公开收藏；信息不足的收藏可从「待确认」查看，再选择加入或不收录。标签判断信息不足时，保留有明确本地证据的基础标签。
- 未修改的规则与模型名称复用已有结果；修改规则、原始书签内容或模型名称后，可重新归类。手动选择不会被覆盖。
- 一键更新：配置好模型后，顶部刷新按钮先导入浏览器收藏，再用当前模型更新全部需要更新的公开收藏；列表上方显示「N 条收藏可用某模型更新 · 全部更新」和进度，可随时停止。每条收藏记录分析所用的模型（提供方、接口地址、模型名），换模型后之前分析过的收藏会重新列入待更新；失败项也在其中，再点一次即重试。整批请求都失败时自动暂停。
- 批量任务可停止后续请求；请求失败时暂停，再次启动会复用已完成的判断。已发出的请求会完成，调用可能产生费用。
- 自动模型分析默认关闭。启用后，仅在侧栏打开时处理待分析及新导入的公开收藏。私密地址和标记私密的收藏不发送，个人备忘不进入模型请求；网址去除认证信息、查询参数及片段。
- 私密地址（只在本机处理，不发给模型、不抓取网页，归入「私密」收藏集）包括：本机与局域网地址；邮箱、云控制台、管理后台、卖家与创作者后台、公司内部系统等后台子域名；飞书、Atlassian、Slack、Sentry、Shopify 店铺等团队专属子域名；Google 文档、腾讯文档、Notion、Figma 设计稿、Overleaf 项目、语雀、石墨、金山文档及各类网盘的具体文件或分享链接；路径前两段为 settings、account、admin、dashboard、my 等的账号页面；带 token、key、session 等凭证参数的网址；成人内容（常见成人网站、.xxx 等专用域名、标题含明显成人字样）。各产品官网首页仍按公开处理。所有外发前的检查统一使用 `src/services/adapters/router.ts` 的 `isLocalOnly`。本地搜索「黄色」「成人」「18禁」等词时直接在本机匹配成人内容收藏，不经过模型。
- DeepSeek、GLM 及通用模型（兼容接口）可提取摘要和自由标签，并执行智能搜索；Jev 做分类和搜索关联，不生成摘要。
- 通用模型分析收藏时，同时从启用的标签库中选择适用标签、判断带收录规则的收藏集（符合／不符合／信息不足），结果与 Jev 的判断同样保存。本地规则已打的标签会一并告诉模型：模型保留的视为确认，明确不保留的记为不符合（用于去掉关键词误标）；模型没看到的标签不记录，本地规则照常生效。用户手动改过标签或手动选择过收藏集的，不交给模型判断。本机模型使用严格结构化输出，标签只能取自标签库。
- 新建或修改带收录规则的收藏集后，尚未被判断的收藏会显示为「可用某模型更新」，点「全部更新」即由模型判断，无需逐条操作（旧版本地决策接口除外）。兼容接口同时支持云端与本机；切换提供方会清除 Key，关闭自动分析。本机未启用认证的通用模型可不填 Key。

## 智能搜索：Jev、云端和本地通用模型

1. 入口统一为「智能搜索」，搜索框为空时也始终显示。尚未配置或启用模型时点击按钮打开配置；已配置模型会提示来源，输入描述后可点击「智能搜索」或按回车。状态明确区分关键词与模糊搜索、智能搜索中及智能搜索结果，进度也会标出「智能搜索」和所选模型。模型设置可选 Jev、DeepSeek、GLM 及「通用模型（兼容接口）」，后者统一接入云端和本机，并提供 Ollama、LM Studio、自定义地址预设。当前只保存一套所选模型配置。
2. 云端模型填写对应 Key、接口地址及模型名称；Jev 使用原来的决策协议，通用模型使用 `/chat/completions`。自定义 HTTPS 接口保存时只申请所填域名的可选访问权限，未授权时不保存；不会一次授予所有网站的访问权限。
3. 在「通用模型（兼容接口）」中可选 Ollama 地址 `http://127.0.0.1:11434/v1` 或 LM Studio 地址 `http://127.0.0.1:1234/v1`，填写服务实际运行的模型名称；也可直接填写其他兼容接口地址。无认证的本机服务可将 Key 留空。是否连接本机由 localhost / 127.0.0.1 地址判定；本机之外只允许 HTTPS，云端需要 Key。不自动切换服务或跟随接口重定向；服务本身是否转发到云端由用户部署决定。打开旧版本地通用模型配置时，显示为统一入口并保留地址、模型名、Key 及开关；取消不修改原设置，保存后统一使用兼容接口配置。切换到另一地址预设会清空模型名和 Key，并关闭自动分析；再次点击当前预设会保留已有配置。
4. 旧版 Laya 本地决策接口保留原协议，仅用于分类；不要用它连接 Ollama / LM Studio，通用模型请选新的本地选项。已有数据库、收藏、手动标签和所选提供方均保留。
5. 允许所选模型分析公开收藏即可主动搜索，自动模型分析可以保持关闭。输入大致描述（例如「之前存的把图片弄小的网站」），输入时只进行本地搜索，点击「智能搜索」或按回车才调用模型。
6. 先本地初筛、再模型重排（`src/services/recallService.ts`）：当前收藏集和处理状态决定范围；本地排序融合全文检索、标签意图（`src/data/searchAliases.ts` 把「把图片弄小」「美股财报」等说法映射到标签）和子串匹配（RRF，k=60），取前 30 条公开收藏（本地命中不足 30 条时，用最近收藏的内容补满），只为这些候选读取网页资料和申请网站权限，再交给模型重排。Jev 一次请求判断一条候选，最多 6 个请求并行，按「匹配」概率排序；通用模型每批 15 条，两批并行。结果中模型判为匹配、相关的排在最前，其余保留本地排序。没找到时可点「扩大到全部 N 条」，把范围内其余公开收藏也交给模型。本地排序同时用于不配模型时的普通搜索。没有新增向量模型或图谱功能。
7. 通用模型结合搜索描述与收藏证据理解意图，返回意图匹配、相关、不匹配或信息不足。每个批次的编号、数量和分类都严格校验，重复编号、未知编号、缺项或无效返回不应用；只能映射到已有收藏，不添加模型编造的链接。没有独立的查询改写调用。
8. 本地通用模型默认请求 JSON Schema 结构化输出，云端兼容模型默认请求 JSON 输出。接口不支持时可关闭「结构化返回」；仍要求合法且完整的结果，不自动重试或偷偷改用另一提供方。连接失败、超时或错误时保留关键词结果和已完成关联。
9. 可停止；修改查询、筛选范围、模型设置或关闭侧栏会取消当前搜索。重复查询、相同模型/接口/提供方/返回模式和相同资料复用内存缓存（最多 2000 条判断），侧栏关闭后清空。修改资料、新增收藏后重新点击搜索。
10. 搜索只发送描述和公开收藏的原标题、去除账号密码/查询参数/片段的网址路径、原收藏夹名、已有原始摘录和标签摘要；私密收藏、个人备忘、自定义标题留在扩展内，包括本地模型模式。每批发送前重读资料，已删除、新标记私密或资料已变的条目跳过，显示结果也会重新校验。
11. 云端请求消耗 API 额度；默认只重排 30 条，「扩大到全部」时范围越大请求和等待越多，可先选收藏集缩小范围。已发出的云端请求取消后可能仍会计费。本地搜索耗时取决于硬件和模型，单批最长等待 90 秒，云端通用模型 45 秒，Jev 20 秒。

### 隐藏的网页资料

- 导入时读取（不调用模型）：点顶部刷新导入后，自动读取已授权网站中还没读过的收藏；未授权的在列表上方显示「N 条收藏可读取网页公开简介，提高分类准确度 · 读取」，点「读取」申请这些具体网站的权限后在后台读取，显示进度并可停止。拒绝后本次打开侧栏不再提示。再次打开侧栏时自动处理已授权网站中新增的收藏。
- 主动搜索、归类已有公开收藏或分析单条收藏时，在点击/回车事件中申请当前范围内、缺少资料的具体 HTTPS 网站权限。拒绝授权仍使用现有资料搜索。不会申请一次访问所有网站。自动分析仅使用已授予的网站权限。
- 从未登录的公开页面读取标题和 description / Open Graph / Twitter 描述，缓存到本机隐藏的 `sourceText`，供本地搜索、基础规则、Jev 和通用模型使用；同时记录网页声明的类型（og:type），规则不认识的网站据此判为「资料」并加「文章」或「视频」标签。采集本身不调用模型，也不修改卡片标题、摘要、功能、手动标签、手动归属或排序；已有模型摘要功能保持原有设置。
- 不携带 Cookie、认证信息或模型 Key，不发送网址查询参数/片段，不抓取私密、内网、账户、登录、订阅或带敏感参数的链接。仅追踪参数会移除；需要查询参数定位视频/文档等具体内容时跳过，避免把其他页面当作原收藏资料。网页按数据处理，不执行脚本，不读取正文，不跟随重定向。
- 公开描述成功缓存 7 天，空描述/不可读取结果缓存 24 小时；首次准备资料可能较慢，每次最多并行 3 页，每页最多 8 秒、256 KiB。可先筛选收藏集缩小范围。已有 GitHub README 等原始资料保留。
- 后台资料变化会清除旧的模型分类判断，手动选择保留。网页变更、私密标记、删除、资料更新或取消发生在请求期间时，丢弃过时结果；网址变化清除旧资料缓存。导出 JSON 会包含这些隐藏资料。
- 登录页、验证页、重定向、无公开描述或依靠脚本加载的页面仍可能读不到资料；因此不能保证凭品牌名识别所有服务，也没有新增 Graph View。

类型检查、构建、三类适配器的模拟响应和浏览器界面已验证；没有调用用户真实 Key 或发送实际收藏。没有实测真实模型的中文检索质量、各云端限额或本机模型性能。只有标题和网址的收藏仍可能因证据不足而找不到。本地模型需能理解中文且按规定返回结果。
